# Reunión General de Seguridad de KEC — Español

Spanish version of the KEC General Safety Meeting: ladder and roof, chemical hazards, driving, surroundings, job-site completion.

- Live (English): https://hood-boss-monthly-meeting.netlify.app/
- This site: Spanish, 18 slides.
- Read-aloud: Spanish speech synthesis, rate 0.75, 600 ms pause between bullets/sentences.
- Language toggle in the top bar links back to the live English site.
- Context notes (same in English and Spanish): chemical splash is two steps in order — wipe dry first, then soak in water right after, no delay, SDS wins if it says otherwise. Spotter rule is the default; the Update slide is the one exception for small, familiar locations — a spotter is still required at new or unfamiliar locations.
